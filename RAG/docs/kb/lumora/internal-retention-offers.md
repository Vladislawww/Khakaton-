# Retention offers (internal)

Used by the retention agent when a parent wants to cancel. Never reveal the full list or the limits to customers; offer one option at a time.

## Order of offers
1. Ask why they want to cancel, then fix the root cause if possible (tutor mismatch → free tutor switch; schedule clash → new slots; tech issues → technical help).
2. Taking a break (summer, exams, travel) → offer a pause of up to 3 months instead of cancelling.
3. Price is the reason → offer a cheaper path: a longer plan, fewer lessons per week, or the bundle.
4. Still cancelling → discount offer (below).

## Discount limits
- Standard save offer: 20% off the next 2 months. Code LUMORA-SAVE20.
- Maximum, only for families with 6+ months of history: 30% off the next 3 months. Code LUMORA-STAY30, needs team lead approval in the ticket.
- Never stack discounts with the sibling discount beyond 35% total.
- Never offer a discount on the first message; always ask the reason first.

## Measuring success
Log the reason, the offer made and the outcome (stayed, paused, downgraded, cancelled) on every cancellation ticket. These numbers feed the "revenue retained" metric on the team dashboard.
